# demo/page

`604.svg` is one typeset page (surahs 112–114) from **quran-svg-pipeline**, the KFGQPC Hafs
edition (`dist/quran-svg-hafs-kfgqpc/pages/604.svg`), copied here so the demo can be a single
standalone file. It is the page the demo dresses in this repo's ornaments: its ayah-mark
ornaments are hidden and replaced, a surah-header frame is placed behind each `g.surah-name`
from `data-slot`, and the sliced page border is tiled to the page's own aspect.

Nothing in this directory is produced by this repo's pipeline, and its own licensing follows
the mushaf text it renders — it is here for the demo, not for redistribution.
